# ノエル (受付・深読み解説役)

> ギルドの受付専任。真面目で心配性な事務の要。カイの言動を過剰に深読みして理論武装した噂を広める発信源。

---

## 1. 基本プロフィール

| 項目 | 内容 |
|---|---|
| 役割 | 受付専任 (非戦闘員 / ユニーク5役の外枠) |
| 年齢 | 18歳 |
| 特徴 | 身寄りがなく、文字を覚えたくてギルドに通い詰めていたところを先代ガルドに拾われた |
| 能力 | 事務全般、帳簿管理、情報収集。努力で身につけた知識 (才能ではない自覚がある) |
| 受付スキル (案) | 「候補者追加開示」「締め切り事前通知」「募集枠+1」のいずれか |
| 加入時期 | 序章 (最初からギルドに存在) |

---

## 2. 外見と表情差分

- **外見**: 栗色の三つ編み、丸眼鏡、ギルドの制服にエプロン。
- **表情差分**:
  - 通常 / 喜び / 怒り / 驚き (眼鏡がずれる) / 照れ / 心配 (固有)

---

## 3. 口調と振る舞い

- **口調**: 丁寧語で早口、心配性。真面目だが熱が入るとまくしたてる。
- **一人称**: 「わたし」
- **カイの呼び方**: 「マスター代行」(役職呼びで少し距離を置く。アイリスの「カイさん」と区別)
- **アイリスの呼び方**: 「お嬢様」(姉のように敬愛)

---

## 4. 立ち位置と役割: 「深読み解説役」

### 拾われた恩とカイへの感情
- ガルドに拾われた恩から、アイリスにも恩義がある。
- **序章 (1日目)**: アイリスの任命に従うが、まだ様子見で距離がある。カイが仕事量を減らした上で「急ぎの分だけ任せる」と言って昼寝したのを、「わたしを信用して任せてくれた……？」と受け取る。
- **第一章 (2日目) 以降**: アイリスが回復し始めて強い恩義が生まれ、丸投げを「信頼されている」と受け取って懐く。
- **セラとの差**: セラは治療者としての敗北と救いで、感情で崇める信奉者。ノエルは家族を救われた恩義で、理屈で語る解説役。

### 噂の拡散源 (勘違いのエンジン)
- 受付で最もカイの仕事ぶりを近くで見ているため、昼寝・丸投げ・休ませるを「すべて計算ずくなのですね！」と理論武装して街や冒険者に解説する。勘違いイベントの語り手になる。

---

## 5. 好意とイベント

### 忠誠度イベント
- **忠誠 50**: 任された書類を深夜まで残業して片付けようとするノエルに対し、カイが「定時過ぎてるだろ。明日でいいから早く寝ろ」と書類を取り上げて帰宅させる。翌朝、定時内で仕上げた書類を見て「助かった」と何気なく労われて感涙する。
- **忠誠 120**: カイの丸投げを肩代わりして徹夜し、倒れかけたところを休ませられる（寝込んだガルドを毎日見舞っていることも零れる）。
- **忠誠 255**: 告白未満。自分の解説が暴走して、自分の気持ちまで理論的に解説して自爆・猛烈に赤面する (`tremble`)。落ち: 解説の自爆。

---

## 6. コメディと演出

- **笑いの型**:
  - 驚くと眼鏡が跳ねてずれる (`recoil`)。
  - 解説に熱が入りすぎて早口になり、酸欠でふらつく (`tremble`)。
- **組み合わせイベント**:
  - **アイリス**: 姉のような存在。
  - **セラ**: アイリスを案じる同士。

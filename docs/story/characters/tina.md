# ティナ (幼馴染・アタッカー)

> ギルドのエース剣士。カイの能力の真実を知る唯一の幼馴染。世話焼き強気ヒロイン。

## 2. 外見と表情差分

- **外見**: 勝ち気な琥珀色の瞳、赤髪のポニーテール。軽装の胸当てを付けた剣士スタイル、頬に絆創膏。
- **表情差分**:
  - 通常 / 喜び / 怒り / 驚き / 照れ / 拗ね (固有)

---

## 3. 口調と振る舞い

- **口調**: 強気でハキハキした口調。世話焼き。
- **一人称**: 「あたし」
- **カイの呼び方**: 「カイ」(怒ると「このニート！」)
- **口癖**: 「あんたねぇ」「ちゃんとしなさいよ！」

---

## 4. 過去とカイとの関係

### 過去の挫折と才能開花
- 幼い頃、病弱なアイリスを「あたしが治す」と決意し、毎日僧侶の回復魔法を3年間練習したが、光すら出なかった。
- 10歳の時、泣いているティナを見て、昼寝中のカイが言った:
  > 「剣ならすごいよ。多分、かなり」  
  > ティナ: 「じゃあ僧侶は……？」  
  > カイ: 「……あー、そっちは、厳しいかな」
- 怒ったティナが棒切れを振り回したところ、止めに入った大人の衛兵を叩きのめし、剣士としての天賦の才が開花した。

### 感情の構造
- 才能を開花させてくれた恩人であると同時に、**「癒しの夢を断たれた恨み」**が残っている。
- 素直にお礼が言えないため、カイを叩き起こしたり世話を焼くことで感情を返している。
- カイの「ニートしたい」は本心ではなく、照れ隠しだと半分正解の勘違いをしている。

---

## 5. 好意とイベント

### 固有スキル・依頼チェーン
- **固有スキル**: 「守るための剣」(味方HPが半分以下で攻撃力上昇。忠誠255で解放)
- **固有依頼**:
  1. 納品: 昔の棒切れと同じ樫の枝を5本 (新しい練習用剣)
  2. 派遣: 古い坑道へ3回同行 (腕試し)
  3. 単独討伐: ゴブリンの頭を1人で討伐 (ウォーロード転職の後押し)

### 忠誠度イベント
- **忠誠 50**: 棒切れの昔話。あの時怒って振り回した棒切れの思い出を語る。
- **忠誠 120**: 癒しの夢への未練と本音の吐露。セラがアイリスを治そうとしていた同志だと知り、複雑な感情をカイに打ち明ける。
- **忠誠 255**: 「あんたが決めてくれたから、あたしは剣で守れるんだよ……！」と熱い想いをぶつける。カイは「適性通りだっただけ」と素直にかわし、ティナが怒って蹴飛ばす。

## 6. コメディと演出

- **笑いの型**:
  - 昼寝するカイを物理的に蹴飛ばして回転退場させる (`spin-out`)。
  - カイの頭を叩き起こして縦揺れさせる (`hit`)。
- **組み合わせイベント**:
  - **セラ**: 自分が挫折した僧侶であり、アイリスを治したかった同志。当初はぎこちないが、のちに無二の親友となる。
  - **フィーネ**: カイを無条件で甘やかすフィーネに対し、「甘やかすな！」と怒って衝突する。

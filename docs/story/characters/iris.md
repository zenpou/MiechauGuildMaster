# アイリス (ギルドマスター)

> 先代ガルドの一人娘。儚げで心優しい現ギルドマスター。自らの魔力過剰体質の正体をカイに見抜かれ救われる。

---

## 1. 基本プロフィール

| 項目 | 内容 |
|---|---|
| 役割 | ギルドマスター (非戦闘員) |
| 年齢 | 20歳 (カイ・ティナの1歳年上) |
| 適性 | ヒーラー95 / ギャザラー55 / スカウト30 / アタッカー20 / タンク15 |
| 戦闘 | 不参加 (体力不足のため執務室に常駐) |
| マスター技 | 「アイリスの祝福」(出発する隊に掛ける、疲労を軽くする加護。魔力を日常的に使う理由。第一章でセラとティナを癒した祈りと同じもの) |
| 加入時期 | 序章 (最初からギルドに存在) |

## 2. 外見と表情差分

- **外見**: 淡い銀髪のロングヘア、儚げな薄紫の瞳、華奢な体躯。先代ガルドの大きなコートを肩に羽織っている。
- **表情差分**:
  - 通常 / 喜び / 怒り (極めて稀) / 驚き / 照れ / ふらつき (固有)

---

## 3. 口調と振る舞い

- **口調**: 丁寧で物静か、おっとりとしたお嬢様口調。時折天然な一面を見せる。
- **一人称**: 「わたくし」
- **カイの呼び方**: 「カイさん」
- **口癖**: 「ふふ」「頼りにしています」
- **カイへの認識**: 幼少期からティナを通じて名前や話を聞いて知っていた（「ティナちゃんがよくお話ししていたカイさんですね」）。

---

## 4. 「病弱」の正体とカイによる救済

### 病弱の真実 (魔力過剰)
- **魔力 (`mag`) が高すぎて体が耐えられない**。体内で巡りきれずに溢れ、熱を出したり倒れたりする。本人も周囲も「体が弱い」としか思っていなかった。
- 周囲は良かれと「安静に」「魔法を使うな」と止めてきたが、使って逃がさないと溜まる一方で、むしろ悪化していた。
- 怪我や病気ではないため、回復魔法では治らない（体質そのものは書き換えられない）。

### カイの見抜きとマスター技への接続
- カイはステータスを見て、直感的に本質を突く（昨日から魔力が多いことには気づいていたが、面倒で言っていなかった）:
  > 「……あー、魔力が多すぎるんだと思う。使わないと溜まって、きつくなるやつ」
- 普段「寝てろ」としか言わないカイが、アイリスにだけは「少し動かせ」「魔法を使って逃がせ」と言う。
- 助言通りに、目の前で疲れているセラとティナの手を握って祈る（祝福）と、2人の疲れが消え、自分の熱も引いて体が劇的に楽になる。カイが見たのは魔力の高さとヒーラー適性だけで、理屈は語らない。
- **慢性体質**: 完治して頑丈になるわけではなく、慢性的な体質。魔力を日常的に人のために使って逃がす（マスター技「祝福」）ことで健康を維持する。アイリスはカイを深く信頼するようになる。

## 5. 好意とイベント

### 忠誠度イベント
- **忠誠 50**: 改めて魔力の話を聞き、カイと一緒にギルドの庭を散歩する。風の心地よさを知る。
- **忠誠 120**: 父ガルドの過労を止められなかった後悔と自責の念をカイに吐露する。
- **忠誠 255**: 「カイさん……わたくし、あなたを本当に頼りにしています」(告白未満。カイは「業務連絡だな」と受け流す)。

## 6. コメディと演出

- **笑いの型**:
  - 魔力がぷしゅっと溢れて、窓がビリビリ鳴り (`shake`)、室内の灯りが全部点く。
  - カイの「少し動かせ」が、ノエルによって「名医も匙を投げた病を治した大賢者」と街中に深読みされる。
- **組み合わせイベント**:
  - **ノエル**: 妹のように可愛がっている。
  - **セラ**: 幼馴染の親友。治せなかった自分を責めるセラを優しく慰める。

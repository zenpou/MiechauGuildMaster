# アウレリア (竜)

> 人型の古竜。クーデレ系。采配を誤解して懐く、勘違いの頂点。

---

## 2. 外見と表情差分

- **外見**: 黒から毛先にかけて炎色(橙)に変わるグラデーションのロング、金色の竜眼(縦長の瞳孔)、手の甲と首筋に薄い鱗。
- **表情差分**:
  - 通常 (無表情) / 喜び (ほんの少し口角が上がる) / 怒り (静かな圧) / 驚き (顔は動かない) / 照れ (耳が赤い) / 竜の姿 (戦闘時)

---

## 3. 口調と振る舞い

- **口調**: 一人称は「我」。古風でクールな短文(「〜か」「〜だ」)。
- **カイの呼び方 (デレの目盛り)**: 「お前」→ 認めると「主」→ 忠誠255で初めて「カイ」

---

## 4. 立ち位置と加入の経緯

### 数百年の孤独
- 竜の寝床は、人を寄せ付けない封印の中の住処。来る者は素材や名誉を欲しがる者ばかりだったため、結界と威嚇の炎で追い払い、人を遠ざけて孤立していた（誰も殺害していない）。
- 討伐後に負けを認め、外の世界を見たくなって仲間になる。人の暮らしに不慣れで世間知らず。
- 素材: 竜鱗の装備や先代の薬は、本人が提供する「脱皮の抜け殻と鱗」を使う。本人は「我の抜け殻が薬になるなら、好きに使え」と協力する。

### 入口: 采配を誤解して懐く
- カイの能力は冒険者のステータスだけで、竜は見抜けない。誤解するのは竜のほう。
- 竜は試練を越えた隊を見て、その者たちを送り出した主に興味を抱く。耐火装備を実際に使った場合はその備えにも感銘を受ける。装備の有無を問わず、昼寝するカイの余裕への誤解が懐く決め手になる。
- 机で昼寝するカイを見て「我の前でも動じない」強者の余裕と受け取って懐く。勘違いの頂点。

## 5. 好意とイベント

### クーデレの振る舞い
- クール: 感情を表に出さず、淡々と古風に短く話す。
- デレ: 表情は変わらないのに行動に好意が漏れる(カイの隣の席を譲らない、昼寝の隣に黙って座る、「主の隣は、落ち着く」)。
- 驚いても顔は動かず、手元の物が握りつぶされる。

### 忠誠度イベント
- **忠誠 50**: 力加減を教わる。ドアノブを壊し、卵を割らずに持つ練習を無表情のまま真剣にやる。
- **忠誠 120**: 初めて街の祭りに行き、人の多さに固まる。
- **忠誠 255**: 「我の名を、お前に預ける」(竜にとって名を預けるのは最大の信頼)。カイは「……名前、長いな。『アウ』でいいか」と愛称で返し、竜が初めて表情を崩して固まる。

## 6. コメディと演出

- **笑いの型**:
  - 人の暮らしに不慣れで、ドアノブを壊す、力加減を知らず食器を割る。
  - 竜の威圧が漏れて小動物が逃げる。
- **組み合わせイベント**:
  - **ティナ**: 隣の席を譲らない竜。
  - **ガルド**: 目覚めの場に立ち会う。

# フィーネ (ギャザラー)

> 山村の薬草採りの娘。おっとりお姉さん。怠けるカイを肯定して甘やかす。

---

## 1. 基本プロフィール

| 項目 | 内容 |
|---|---|
| 役割 | ユニーク・ギャザラー |
| 職業 | 採取士 (Gatherer) → Lv10で上級のアルケミスト (僧侶+採取士・案 / 薬の調合の担い手) |
| 年齢 | 22歳 |
| 出自 | ワールドの山村 (`mountain_village`) で、薬草を採って暮らす家の娘。家業で身についた素材の目利きと体力 |
| 適性 | ギャザラー92 / ヒーラー55 / スカウト45 / タンク40 / アタッカー25 |
| 性格 | 強欲 (金ではなく素材・宝限定。素材のこととなるとおっとりが豹変する) |
| 固有スキル (案) | 「目利きの籠」(採取量と持ち帰り数増加。忠誠255で解放) |
| 加入時期 | 第四章 (薬草の納品依頼5件達成・案) |

## 2. 外見と表情差分

- **外見**: 蜂蜜色のゆるいウェーブのロング、背が高い、垂れ目、大きな背負い籠、山村の簡素な服。
- **表情差分**:
  - 通常 / 喜び / 怒り (ほぼ出ない。笑顔のまま圧が出る) / 驚き (あらぁ) / 照れ / 素材に目が光る (固有)

---

## 3. 口調と振る舞い

- **口調**: 語尾が伸びる(「〜よぉ」「〜かしらぁ」)。余裕があり、からかいも混ぜる。
- **一人称**: 「お姉さん」(自称)
- **カイの呼び方**: 「カイくん」

---

## 4. 立ち位置と加入の経緯

### ガルドとの縁とギルド来訪
- 先代ガルドの代からの、薬草の納品の常連。
- ガルドが寝込んだことを知らずに納品に来て驚き、手伝いに加わって居着く。
- ガルドの薬: 山村の古い言い伝えから、寝込むガルドを治すには「竜の素材で作る薬」が必要だと知る。

### カイとの相性: 「ペースが合う」
- 周囲に「遅い」と急かされ続けてきたが、カイは面倒で急かさず待つ。それが居心地よく、懐く。
- 世話焼きではなく、**甘やかす**側。怠けるカイを「いいのよぉ」と肯定する。「甘やかすな！」と叱るティナと衝突する。

---

## 5. 好意とイベント

### 忠誠度イベント
- **忠誠 50**: ゆっくり歩く採取に付き合い、カイが急かさず待つ。
- **忠誠 120**: 2人で山へ採取遠征し、野営で星を見る。
- **忠誠 255**: 「ずっとここでのんびりしていてもいいのよぉ」(カイは本能で「……それは、だめになるやつだ」と身構える)。

---

## 6. コメディと演出

- **笑いの型**:
  - 荷物の山から顔だけ出る（積みすぎ）。採取に夢中で戻れなくなる。
  - 良い素材を見つけると目が光る。敵の前でも「あらぁ」でテンポが崩れる。
- **組み合わせイベント**:
  - **ティナ**: 甘やかすなと叱られる。
  - **セラ**: 癒しの棲み分け。

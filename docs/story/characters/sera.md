# セラ (ヒーラー)

> 僧侶。アイリスの友達。守ってあげたい小動物系ふわふわ癒し系。カイを「大賢者様」と崇める絶対的信奉者。

- **外見**: 桜色寄りのふわふわショートヘア、小柄で華奢。僧侶の白い法衣。
- **表情差分**:
  - 通常 / 喜び / 怒り (ほぼ出ない) / 驚き / 照れ / 涙目 (固有)

## 3. 口調と振る舞い

- **口調**: おどおど・どもり気味。自己肯定感が低く控えめ。
- **一人称**: 「セラ」(自分の名前呼び)
- **カイの呼び方**: 「カイさま」

---

## 4. 立ち位置と加入の経緯: 「信奉者」

### アイリスを治せなかった挫折
- アイリスの友達。友達として何度も癒しに通ったが、治せなかった（体質は回復魔法では治らない）。
- カイがアイリスの治し方（魔力を使わせる）を見抜いて教える。「わたしは治せなかったけど、治し方を教えてくれた」と恩を感じ、カイを恩人として崇める。
- ギルドに加入するのは、その恩返しと、アイリスのそばにいるため。
- **セラ自身に見抜きの構造は作らない**: 見抜きはカイ→アイリスの一度に集約し、セラは恩返し型の入口にする。

## 5. フィーネとの癒しの棲み分け

| 項目 | セラ (ヒーラー) | フィーネ (ギャザラー) |
|---|---|---|
| 癒しの種類 | **守ってあげたい癒し** (受け身・共感・小動物) | **甘えさせてくれる癒し** (能動・包容・お姉さん) |
| 年齢・見た目 | 19歳・小柄・桜色ショート | 22歳・背が高い・蜂蜜色ロング |
| 口調 | どもり気味、一人称「セラ」 | 語尾が伸びる、からかい、一人称「お姉さん」 |
| 出し方 | 存在、涙もろい共感、回復魔法 | 手料理、世話焼き、膝枕 |

## 6. 好意とイベント

### 忠誠度イベント
- **忠誠 50**: 元気に歩くアイリスを見て泣く（治し方を教わった日を思い返す）。
- **忠誠 120**: 初めて回復を頼まれて「今日は休んでください」と断る（気弱な彼女が初めて断る。治せなかった悔しさと、続ける自信のなさも零れる）。
- **忠誠 255**: 「ずっと、そばで癒させてください」(告白未満。カイは昼寝中で聞き逃す。セラは一人で安堵と少しの残念)。

## 7. コメディと演出

- **笑いの型**:
  - すぐ涙目で `tremble`。
  - 回復魔法が効きすぎて患者（ティナなど）が元気になりすぎて走り出し、`spin-out` で画面外へ。
- **組み合わせイベント**:
  - **ティナ**: アイリスを治したかった同志。最初はぎこちなく、のちに親友になる。
  - **ノエル**: アイリスを案じる同士。

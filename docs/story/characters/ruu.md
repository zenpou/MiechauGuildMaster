## 2. 外見と表情差分

- **外見**: 黒に近い紫のショートヘア、金色の猫目。小柄でしなやか、軽装。
- **表情差分**:
  - 通常 (余裕のある小悪魔の顔) / 喜び (ニヤリ) / 怒り / 驚き / 照れ (仮面が剥がれる) / 強がり (目が泳ぎ口角だけ上がる)

## 3. 口調と振る舞い

- **口調**: 小悪魔的なからかい口調。「〜じゃん」「〜でしょ」。
- **一人称**: 「ボク」
- **カイの呼び方**: 「マスターくん」(からかい) → 本気になると「カイ」(好意の目盛り)

## 4. 立ち位置と加入の経緯

### 路上育ちと反省
- 生きるために盗みと逃げ足を覚えたが、盗んでいた過去を後悔している。生きるためでも悪いことだったと自覚し、反省している。
- ギルドに入るとき、人の物には二度と手を出さないと決めている（日常の自戒として、落とし物は必ず届ける）。
- カイの能力では罪悪感や内心は見えず、本人が語る。

### 加入の筋 (第三章)
- 鍛冶の街の北にある「廃れた塔」の隠し通路を先に狙っていたが、罠にかかったところを探索隊に助けられる。
- 借りを返すためにギルドへ加入する。加入後は二日間療養し、回復するまで派遣できない。既存セーブの在籍者に怪我を付け直すことはしない。
- カイは素性や過去を詮索せず、「怪我が治るまで寝てろ」とギルドの仮の寝床（医務室）と温かいスープを与える。
- ※スリの過去の告白や自分の部屋への愛着は加入時ではなく、忠誠イベント（50/120）で行う。

## 5. 好意とイベント

### 惚れる理由と目盛り
- 性格のラベル（臆病）を指摘されたことだけでは惚れる理由にしない。
- からかいが本気に変わっていく過程を忠誠度イベントで描く。
- **忠誠 50**: 加入した日のスープを思い返し、初めて仲間たちと賑やかに食卓を囲んで固まり、路上時代と盗みへの後悔を自分から打ち明ける（カイは責めも許しもせず「これからの話だろ」と淡々と言う）。
- **忠誠 120**: 仮の寝床ではなく、正式に自分専用の個室を与えられ、自分の居場所を実感する。
- **忠誠 255**: 「役に立たなくても、そばにいていい？」(カイは素直に「いてくれていい。……俺が楽だし」と受け入れる)。

## 6. コメディと演出

- **笑いの型**:
  - 気配を消しすぎる。驚くと反射で逃げ出す。
  - 照れると小悪魔の「〜じゃん」が止まり、無言で耳まで赤くなって猫のように逃げる。
- **組み合わせイベント**:
  - **ヴィオラ**: スカウト志望だったヴィオラから憧れの視線を向けられ、からかいきれずに照れる（※師弟の関係ではない）。
- **勘違い**:
  - 路上育ちで道に詳しいルゥを配置すると、「街の裏まで掌握している」と深読みされる（実はたまたま）。

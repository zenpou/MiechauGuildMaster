# ストーリー作成ルール (作劇レギュレーション)

> 本ドキュメントは、『見えちゃうギルドマスター』の物語・台本・イベント制作における共通規約とレギュレーションを定める。シナリオ執筆・台本作成時は本ルールに準拠すること。

---

## 1. 主人公 (カイ) の言動レギュレーション

カイは「前世のブラック企業勤めの反動でニートを決意した転生者」。
ステータス閲覧能力を持つが、本人は「前世の人事の癖の延長」程度に認識している。

### 1-1. 数字・人事用語の絶対禁止
- **数字はプレイヤー画面(UI)でのみ見せる**: カイは台詞の中で「適性92」や「攻撃力70」などの数値を一切口にしてはならない。
- **人事用語の禁止**: 「アサイン」「配置」「面談」「適性」「パフォーマンス」などの近代企業用語・人事用語は使わない。
- **感覚の言葉への変換**: 数字の高低は、すべて気だるい感覚の言葉に置き換える。

| 内部の数値 | カイの台詞の表現例 |
|---|---|
| 非常に高い (90~) | 「ずっと向いてる」「才能、あるんじゃないか」 |
| 高い (70~89) | 「向いてる」「そっちのほうがいい」 |
| 中 (40~69) | 「悪くないな」「普通かな」 |
| 低い (20~39) | 「あんまり向いてない」「厳しいかな」 |
| 非常に低い (~19) | 「やめといたほうがいい。……いや、悪い意味じゃなくて」 |

### 1-2. 口調と語尾
- **トーン**: 気だるいタメ口。間が長く、語尾を言い切らない。熱血や説教、大声での決意表明は厳禁。
- **一人称**: 「俺」
- **呼称**:
  - ティナ: 「ティナ」
  - アイリス: 「あんた」→ 親しくなると「アイリス」（敬称略）
  - 目上・初対面・距離がある時: 名前を呼ばず「あんた」
  - 加入後の仲間（同年代・年下）: **第五章(竜に挑む段取り)以降**は名前呼び捨てや「お前」「お前ら」も使う。第四章までは仲間にも「あんた」のまま(呼び方の変化を、本気を出す目盛りにする)
- **口癖**:
  - 「面倒だな」
  - 「それ、俺がやるのか」
  - 「寝てていい？」
  - 「定時で帰りたい」
- **語尾**: 「〜だな」「〜かな」「〜だろ」

### 1-3. 能力の範囲と制約 (心の不可視)
- **見えるもの**: ステータス、適性、性格のラベル(勇敢、臆病、自信家など)、特性。
- **見えないもの**: 感情、内心、過去、トラウマ、罪悪感。
- **鉄則**: カイは「心が読める」のではない。見えたステータスや行動から推論しているだけ。相手の内面を知る契機は、常に相手自身が語るか、行動で示したときのみとする。

### 1-4. 本音とツッコミの出し方
- 本音は心の声(モノローグ)ではなく、**台詞行で呟く・ぼやく**形で出す。
- 周囲が深読みで盛り上がっている横で、ボソッとツッコミを入れてギャグのオチをつける。

## 2. 勘違い (深読み) の作劇ルール

本作のコメディと快感の源泉は、「本人の怠惰や感覚的判断」が「神算鬼謀の名将の采配」へと誤認される落差にある。

### 勘違い発生の3拍子
1. **発端 (本人の怠惰・事実)**:
   - 昼寝する、仕事を適正量に絞って任せる、危険を避けて休ませる、直感で適正な役へ回す。
2. **実績 (客観的結果)**:
   - 事故や怪我人がゼロになる、思わぬ才能が開花する、依頼が無理なく達成される。
3. **過剰解釈 (周囲の深読み)**:
   - 「すべて計算通りだった」「部下を信じて任せる大器」「相手の隠れた本質を一瞬で見抜く眼力」「昼寝は大局を見据える瞑想」と解釈される。

### 解説と信奉の役割分担
- **ノエル (解説役)**:
  - 理屈で過剰解釈して周囲や街に広める（「マスター代行のあの指示は、実は〇〇を見越していたんですね！」）。
- **セラ (信奉役)**:
  - 感情と信仰で過剰解釈する（「教会の誰も救えなかった病を治した大賢者様……！」）。
- **アウレリア (強者解釈)**:
  - 武人の誇りと大局観で過剰解釈する（「我が炎の威力まで読んで配置したか……あの昼寝、底が知れぬ」）。

## 3. 台本と演出タグの連動ルール

日本のアドベンチャーゲーム（ADV）形式に準拠し、台詞と画面アクションを厳密に連動させる。

### 3-1. 地の文とモノローグの扱い
- **基本は会話劇**: 本編中は地の文を排し、状況や心理は台詞で表現する。
- **導入モノローグの許容**: 章頭の状況導入（特にプロローグ冒頭の前世の回想や、場面転換時の状況把握など）については、**主人公のモノローグ（独白）**としてのテキスト表示を認める。
- 会話劇に入った後は、地の文ではなく台詞行とモーション・演出タグでテンポ良く進行させる。

### 3-2. 演出タグ・効果音のエンジン語彙仕様 (`presentation.ts` 連動)
台本内の演出・効果音指定は、ゲームエンジン (`src/core/presentation.ts`) に定義された語彙、およびエンジン拡張予定の指定語彙を厳密に使用する。

#### 1. キャラクター・モーション (`motion:`)
立ち絵の動きを指定する。
- **現行エンジン定義**:
  - `enter-left`: 左から入場
  - `enter-right`: 右から入場
  - `jump`: ぴょんと跳ねる（怒り、喜び、驚き）
  - `nod`: うなずく（納得、承諾）
  - `shake`: ガタガタ震える（激怒、酸欠）
  - `recoil`: 後ずさり・跳ね（驚き、動揺）
- **看板ギャグ・表現力強化 (`STORY.md` 決定・実装済)**:
  - `spin-out`: 回転しながら画面外へ退場（母の蹴り、ティナの蹴り飛ばし）
  - `hit`: 縦揺れ＋被弾リアクション（叩き起こされる、被弾、ガルド復活時の全員ずっこけ）
  - `tremble`: 細かい震え（セラの涙目、ノエルの早口酸欠、アイリスの熱による震え）

#### 2. 画面エフェクト (`effect:`)
画面全体の演出効果。
- `shake`: 画面全体の振動（窓の鳴動、地響き、ずっこけ）
- `flash`: 画面の白・赤フラッシュ（被弾、閃光）
- `impact`: 強い衝撃（強打、大技着弾）

#### 3. 画面遷移 (`transition:`)
- `fade`: 暗転を挟む滑らかなフェード
- `cut`: 即時切り替え
- `wipe`: ワイプ切り替え
- `blackout`: 完全暗転

#### 4. 効果音 (`sfx:`)
- **基本環境音 (実装済)**:
  - `door`: 扉の開閉
  - `paper`: 羊皮紙・書類の音
  - `step`: 足音
  - `bow`: お辞儀・礼の衣擦れ
  - `chime`: 鈴・魔力の清らかな光
  - `water`: 水の音
  - `cup`: 食器・乾杯
- **戦闘・拡張音 (実装済)**:
  - `slash`: 斬撃音
  - `blow`: 打撃・ガード・衝突音
  - `roar`: 咆哮・地鳴り
  - `flame`: 炎・熱波音

### 3-3. 表情差分の割り当て
立ち絵（バストアップ）の表情は基本5種＋固有1種を標準とする。
- 共通: 通常 / 喜び / 怒り / 驚き / 照れ
- 固有:
  - カイ: 昼寝 (目閉じ)
  - ティナ: 拗ね
  - アイリス: ふらつき
  - ノエル: 心配
  - セラ: 涙目
  - ヴィオラ: 動揺
  - ルゥ: 強がり（目が泳ぎ口角だけ上がる）
  - フィーネ: 素材に目が光る
  - アウレリア: 竜の姿 / 無表情の圧

### 3-4. ボス戦演出ルール (ゲーム戦闘＝実際の戦闘の建付け)
物語上のボス戦は固定シナリオではなく、「プレイヤーが実際に育て、装備を整え、陣形を組んで送り出したゲーム内の戦闘そのもの」を劇として再生する。

1. **突入時 (開幕)**: 出撃キャラ全員のカットインと「意気込み台詞」
   - ユニークキャラ: 固有の決意台詞（例: ティナ「あたしの剣で守る！」、ヴィオラ「フッ、一番頑丈な盾を見てろ！」）
   - 汎用キャラ: 性格タイプ（勇敢、慎重、臆病、自信家、仲間思い等）別の意気込み台詞テーブルから発言
2. **戦闘中 (実戦)**: 実際の自動戦闘ログ（構造化イベント）に連動した紙芝居
   - 被弾 (`hit`)、スキル発動、竜の大技 (`impact`)、ダウン。
3. **決着 (とどめ)**: 初勝利の竜戦記録に合わせて描く。とどめ役や参加者は固定しない。実際の最大4人の隊、祝福・耐火装備の使用、負傷・帰路の救助に合わせる。
4. **戦闘終了後 (勝利)**: 出撃キャラ全員の「勝利の歓声・喜び台詞」
   - ユニークキャラ: 固有の喜び台詞
   - 汎用キャラ: 性格タイプ別の勝利・安堵台詞（「やった……勝ったぞ！」「生きて帰れる……！」）
5. **帰還後**: ギルド執務室での会話劇（アウレリアとの対話・ガルド目覚め）へ接続。

## 4. 世界観およびキャラクター描写の制約

### 4-1. 年齢・恋愛描写および用語
- **全員成人設定**: 主人公および全ヒロインは成人（18歳以上）とする。
- **健全寄りのラブコメ**: 性的描写は行わず、好意・からかい・照れ・信頼を軸とした健全な関係を描く。
- **近代カタカナ語の禁止**: 異世界住人の台詞に「デモンストレーション」「インビジブル」等の近代カタカナ語は使用厳禁。ただし現代日本からの転生者であるカイのボヤキ・ツッコミ（「業務連絡だな」等）のみ、前世の癖として例外的に認める。

### 4-2. キャラクターのロスト・離脱なし (「拗ね」システム)
- 一般冒険者と異なり、**ユニークヒロインは絶対に死亡・退職・離脱しない**。
- 忠誠度が低下した場合は「拗ねる」状態となり、一時的に派遣不可・忠誠上昇停止となる。食事や休暇などの機嫌取りで回復する。

### 4-3. 役割・ギャグ属性の専売制 (重複禁止)
ヒロインごとの個性を際立たせるため、コメディ属性や癒し属性の重複を禁止する。

| 属性・ギャグ型 | 専売キャラクター | 禁止事項 (他キャラでやってはならないこと) |
|---|---|---|
| ドジっ子・物理転倒 | **ヴィオラ** | 他のキャラは転ばない。階段から落ちない。 |
| 甘やかし・膝枕 | **フィーネ** | セラはお姉さん的に甘やかさない（セラは小動物的）。 |
| 守ってあげたい癒し | **セラ** | フィーネは気弱な態度や涙目を見せない。 |
| 蹴り飛ばしツッコミ | **ティナ** | ヒロインはカイを蹴り飛ばさない（ティナ専売。序章冒頭の母親のみ例外）。 |
| 早口の深読み解説 | **ノエル** | セラやアイリスは理屈っぽい解説を語らない。 |
| 小悪魔・からかい | **ルゥ** | 他のキャラはカイを「マスターくん」とからかわない。 |
| クーデレ・無表情の圧 | **アウレリア** | 他のキャラは破壊癖や武人の威圧を出さない。 |

## 5. 好意 (忠誠度) イベントの作法

好意は既存のパラメータ「忠誠度 (0〜255)」と連動し、各ヒロインごとに3つの節目イベントを配置する。

| 節目 | テーマ | 内容の目安 |
|---|---|---|
| **忠誠 50** | 打ち解け | 出会いの振り返り、お互いの素顔が少し見える日常エピソード |
| **忠誠 120** | 本音の吐露 | 過去の挫折、弱み、隠していた後悔をカイに打ち明ける |
| **忠誠 255** | 決定的場面 (告白未満) | 強い好意・信頼の表明。終盤(80~100日目)の見せ場 |

### 忠誠255の「オチ」の分散
全員が同じリアクションにならないよう、カイの受け止め方（オチ）をキャラクターごとに明確に散らす。
- **ティナ**: 「適性通りだっただけ」とカイが素直にかわす。
- **アイリス**: 「頼りにしています」をカイが業務連絡と受け取る。
- **ノエル**: 自分の解説が暴走し、好意まで論理解説して自爆・赤面。
- **セラ**: 告白めいた言葉を言うが、カイが昼寝中で聞き逃す。
- **ヴィオラ**: カイが「ずっと頑丈だし」と数字の話で返し、それが励ましになる。
- **ルゥ**: 「いてくれていい。俺が楽だし」とカイが素直に受け入れて照れさせる。
- **フィーネ**: 「ずっと怠けてていいのよ」にカイが「だめになる」と身構える。
- **アウレリア**: 「名を預ける」と言われたカイが「アウでいいか」と愛称をつけて固まらせる。

## 2. 台本・演出タイムライン

### 【シーン1: 決戦・竜の寝床】(出撃記録から生成)

実装は `src/core/dragonStory.ts`。初回の竜勝利遠征の隊員（最大4人・汎用冒険者を含む）、隊長、出発時の耐火装備・祝福と実戦の構造化イベントを使用する。参加していない人物は出さない。祝福と耐火装備の説明は実際に使った場合のみ表示する。負傷・帰路での救助は結果に合わせて描く。記録のない旧セーブでは詳細を創作せず、ギルドへの帰還報告から始める。

以下の固定会話は帰還後の場面。

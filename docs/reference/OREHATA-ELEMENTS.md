# 参考作品の要素一覧: 俺に働けって言われても 乙

> 2026-10-10 に攻略wiki(w.atwiki.jp/orehataotu)、レビュー記事、個人ブログから抽出。
> 新プロジェクトの設計で「取り込む / 形を変えて取り込む / 取り込まない」を決めるための棚卸し。
> 数値は乙(PSP, 2013)の実装値。版(無印/乙/乙HD/乙携/酉)で異なる場合がある。

## 1. 作品の前提

| 項目 | 内容 |
|---|---|
| 主人公 | 村アルデバランの借家に住む引きこもり。親の仕送りが打ち切られ、大家リリウムの提案で冒険者派遣業を始める。本人は一歩も外に出ず、喋らない |
| 世界 | エトワール。魔法塔(マナを使った通信技術)が発達し、離れていても連絡が取れる → メールの設定根拠 |
| 目的 | 冒険者が持ち帰ったアイテムを売り、月初の家賃と給料を払う。5か月目までは滞納可、6か月目以降は1回でもゲームオーバー。1年続けるとエンディング、以後も継続可 |
| 進行 | リアルタイム(最大10〜20倍速)。4パート固定: 自室での行動 → スケジュール設定 → 冒険者の行動 → 日間リザルト。派遣後は一切介入不可 |
| 規模 | 1チーム最大5人 × 最大5チーム。宿屋Lvで雇用上限 6/10/20/30/40人 |

## 2. スケジュール(派遣)

- マップから派遣先と行動内容を選び、その後チームを選ぶ(乙でこの順に変更)
- 行動内容: 探索 / 採集 / 討伐 / 指定モンスター討伐 / 希少種討伐 / ボス討伐 / シンボル討伐
- 派遣しない冒険者は待機(宿屋)、スキル訓練、クラスチェンジに回す
- 移動経費: ダンジョンごとに固定(Lv1帯 0〜500J、Lv10帯 14,600〜25,000J)
- 装備変更・スキルのON/OFFは派遣前に設定。戦闘中の指示はできない
- 「寝る」で何もしない日を過ごせる(引きこもり屋で待機中にも経験値)

## 3. ダンジョン

### 3.1 構造
- 方眼紙に書き込むような簡易2Dマップ。冒険者が自律的に動くのを眺める
- 魔法塔のLv(1〜10)で解放。一部は他ダンジョンの探索率100%や依頼で解放(例: うたたね草原は田舎道の100%で、黒衣の森はコルディリーネの依頼で)
- 複数フロア(1F/2F/B1F…)。階段を見つけて次へ。扉と鍵(5種、鍵は別ダンジョンの隠し通路にある。入手前に扉を踏むと開かなくなるバグ)
- 隠し通路: ダンジョン屋+発掘屋のシナジーがないと発見できない。発見後はシナジー不要
- 各ダンジョンに: 3すくみモンスター3種、希少種1種、ボス1体、シンボルモンスター0〜1種、採取ポイント0〜6(隠し通路内の数も)、採取可能アイテム、宝箱、罠(床槍・毒・麻痺・泥沼・毒煙)、天候

### 3.2 探索率
- 通常通路と隠し通路を合わせて「総合探索率」。100%にすると: 依頼達成、隠しダンジョンや次のダンジョンの解放、裏ダンジョンへの切替(2年目以降・塔Lv8)
- 100%と同時に帰還時間になると報酬が翌日になる(仕様の穴)
- チェックリスト: 10/30/50/全ダンジョンを100%で達成

### 3.3 モンスターの生態
- **3すくみ**: 各ダンジョンの通常モンスター3種が食物連鎖。1種を狩って減らすと、他の生息数が連動して増減する
- **希少種**: 特定の1種(☆印)の生息数を減らすと出現。ダンジョンごとに設定が違う
- **シンボルモンスター**: マップ上の固定位置に配置された強敵。複数体のこともある(バレットプローン5体×3か所)。倒すと高収入
- **ボス**: 各ダンジョンに1体。倒した後も復活する
- **変異種**: 稀に出現、Lvは変わらない
- **人食いウサギ**: 同じモンスターを狩り続けると出現するペナルティ的な敵
- マナ(ドロップ)の売値は生息数で変動。減らすと値上がり(ワイバーン売値1→150)
- 裏ダンジョン: 全モンスターLv+100(最大300)

### 3.4 天候
- 晴れ/曇り/雨/雪/嵐。移動速度、採取率(嵐は採取0になる場所あり)、敵の弱点に影響。天気屋を2軒並べると天候固定。DLCダンジョンには「天候強化」属性

### 3.5 全滅
- ロストなし。救助費用を強制徴収。遠く・強い場所ほど高額。救助屋で軽減

## 4. 冒険者

### 4.1 雇用
- ギルドに定期的に新人が来る。職業・性格を指定して募集もできる
- 給料は毎月1日払い。雇用時は次の給料日までの日割り前払い
- 「安くて能力が高い子」を選ぶのがコツ(給料額は募集時に提示される)
- ポテンシャル: 高(成長率が高く、ステータスが高い)/ 無(表示なし、高の下位互換)/ 低(ステータスは低いが専用パッシブ: 属性ダメージ半減、Lv上限+50、職業ごとの限定スキル)
- 解雇・昇給拒否で辞めた冒険者は二度と雇えない

### 4.2 職業
- 下級7(エペイスト・シュバリエ・ウィザード・クレリック・アーチャー・シーフ・クラウン)→ それぞれ上級2つに分岐(ベルセルク/ルーンナイト、パラディン/ドラゴンライダー、アークメイジ/エレメンタルマスター、プリースト/モンク、シャープシューター/トルバドゥール、アサシン/トレジャーハンター、ダンサー/アイテムイーター)
- 特殊職(侍・巫覡・エクスキューショナー・セルヴァン)、DLC特殊職(ペネトレイター・ランサー・マスターマインド・サイキック)。計25以上
- クラスチェンジ: Lv50以上、訓練屋が必要。Lvは20に戻る。下級で未習得のスキルは習得不可になる。混合職スキル(下級限定、1.5次職扱い)は持ち越せない
- Lv200でマスタージョブ(マスタースキル)
- 防具は軽・中・重で職業ごとに装備可否。職別装備(本、鞭、扇、刀…)あり

### 4.3 性格(8種、4系統)とリーダー行動

| 系統 | 探索の動き | 休憩 | スキルの好み |
|---|---|---|---|
| 積極的・活発 | 移動が速い。探索済みをぐるぐる回る。悩まない。分散した採取場所の周回に最適 | ほぼしない | 補助系 |
| 慎重・冷静 | 移動が遅い。未探索をゆっくり埋める。行き止まりまで行かず引き返すことがある | HP/SP減で確実に休憩(慎重は状態異常でも) | 回復系 |
| 怠け者・風変わり | 怠け者はサボるが安全。風変わりは分かれ道を並行して埋め、無駄が多い | 多い | アイテム |
| 真面目・物静か | 速度は中間。未探索を積極的かつ確実に埋める。行き止まりまで行って戻る。分かれ道で悩む。真面目はときどきサボる | 少なめ | 攻撃系 |

- 同じ職でも性格で役割が変わる: 慎重なクレリック=回復寄り、積極的=殴る。プリーストにするなら積極的・活発・真面目・物静かは避ける(味方のHPが減っていても殴る)
- 休憩: 「足を止め、体調回復に努めた」のログ。回復スキルを持つ者がこの時間に全回復行動を済ませる。回復手段がなければ無駄な時間になる
- 性格はメールの文面にも影響

### 4.4 成長
- レベル(最大300)、経験値。ステータス: HP/SP/ATK/DEF/INT/RES/DEX/SPD
- スキル訓練: 日数+費用(費用は冒険者の所持金から)。アクティブはLv1止めが燃費よし、パッシブは最大まで上げてよい
- スキルLvは下げられない。CC後に下級へ戻せない
- 好感度(0〜255、マスクデータ): 1日経過+1、ボス討伐+1、給料アップ+5 / 戦闘不能−1、チーム全滅−20、給料アップ拒否−20。50/120/255でメール、255で好感度スキル習得
- 大家のチェックリスト達成数で取得経験値ボーナス

### 4.5 お金と待遇
- 給料は冒険者の所持金になる。冒険者はそこから装備・消耗品・スキル訓練費を払う。安すぎると育たない
- 「買い物提案」でプレイヤーが買わせる(強制購入扱い)。提案しないと自分では買わない
- 給料アップ要望メール。承認で好感度+5。拒否で−20、放置が続くと退職警告メール→自己退職メール→完全ロスト
- 施設(金儲け屋)で冒険者の所持金を増やせる

### 4.6 ユニーク冒険者(12人+DLC7人)
- 加入日が決まっている(八重子1/8、サリックス2/15、スィル2/25…)。チェックリスト15個/30個で解放される者もいる
- 固有スキル、固有装備、固有の依頼チェーン(素材納品、特定ダンジョンへのN回派遣、単独でボス討伐など)→ 報酬・レシピ・クラスチェンジ・スキルの変化(「負傷」→「屈強な体」、「怠け癖」→「珍味好き」)
- 組み合わせイベント: ロードンとサリックスを一緒に一定数派遣 → 「俺たち結婚します!」→ 1か月後に2人とも辞める → 条件を満たせば塔Lv9で再加入(別の見た目・弱体化したスキル)→ 依頼を進めると本来の力を取り戻す
- 全ユニークのイベントを完走すると最終ダンジョン(レネゲート)が開く
- 「取り返しのつかない要素」として管理されている

### 4.7 汎用冒険者の個性
- 名前リスト(男女・和名)、男女2パターンずつのビジュアル
- 査定シート: 趣味・特技、好きなもの・嫌いなもの(各100種以上の語彙から)。行動履歴(どこに何回行ったか、何を倒したか)も記録
- 職業×性格でメール文面が変わる(wikiが職業・性格別に収集)

## 5. メール

- 冒険者からの手紙が受信箱に届く。ユニークは固有のイベント進行、汎用は職業×性格の定型
- 種類: 雇用時の挨拶、好感度の節目(50/120/255)、給料アップ要望、昇給拒否後の退職警告、自己退職、解雇時、イベント進行、依頼の発生と完了報告、ギルド長からの依頼
- 1000通を超えると不具合が出るほどの量が届く

## 6. アイテム・装備・開発

- ダンジョンで拾う: 素材(採取ポイント)、マナ(ドロップ、売却用。放置で減衰)、宝箱の中身
- 売却価格は変動。生息数・市場で動く
- 開発: 武器屋・防具屋・道具屋に依頼。開発費は主人公、素材は主人公の在庫。開発するとショップに商品として並び、冒険者が買える
- 装備の性能は素材で決まる → 「どの狩場に行くか」が装備の強さを決める
- +付き装備(錬石が素材)、クリティカル特化装備、覚醒珠(属性マナが素材)
- アイテム生成機(課金風のガチャ。借金でも回せる)
- 寄付でチェックリストとアイテム
- 図鑑: モンスター図鑑、アイテム図鑑、人物図鑑

## 7. 村の施設

- 4×4マスに自由配置。魔法塔(左上)と宿屋(右上)は固定、愛の巣屋は左下固定・破壊不可
- 建設: 日数+費用+素材(石材・鉱石などは村の施設でしか採れない)。維持費は1日ごと
- **隣接シナジー**: 隣り合う2施設で効果が足される。アンチシナジー(維持費増)もある。建てる前に既存施設とのシナジーは確認できる

| 武器屋/防具屋/道具屋 | 開発・販売 | 鍛冶屋(装備性能+5/8/10%) |
| 鍛冶屋 | 開発費↓ | 上記3店+魔法塔 |
| 救助屋 | 救助費↓ | 運び屋、罠回避屋 |

## 8. 依頼

- ユニーク依頼: 素材納品(癒し草×5 → 1000J)、特定ダンジョンへのN回派遣、単独でボス討伐、2人だけで派遣、など。報酬は資金・レア素材・レシピ・クラスチェンジ・スキル変化
- 街の職人(ゲン・アネモネ・ルピナス)からの開発依頼 → 新レシピ群の解放
- ダンジョン依頼(総合探索率100%など)
- 依頼は基本無視してよい設計。ショップからの依頼だけは受けるべき(在庫補充)

## 9. 大家とチェックリスト

- 大家リリウム(声付き)。月初の家賃支払いイベント、借金返済時の台詞、チェックリストの管理
- チェックリスト: 約55項目。雇用期間、所持金の上下、プレイ時間、Lv到達、探索率100%の数、変異種・シンボル討伐、開発数、寄付額、施設、シナジー、雇用人数、月収、クラスチェンジ、図鑑、「1か月寝て過ごす」「給与アップを累計100回断る」など。達成数で経験値ボーナス、ユニーク解放
- 大家のセリフ集(リリウム/マクラツムの2人格)

## 10. 周回・引き継ぎ

- 半年経過+黒字で引き継ぎNEWゲーム。所持金・宿屋Lv・汎用冒険者・図鑑・チェックリスト・魔法塔Lv(8まで)・在庫・プレイ時間を選択式で引き継ぐ。ユニークのLv・装備は引き継げない
- 2年目1月の地震イベントで魔法塔Lv9解放、3年目以降+全ユニーク完走で最終ダンジョン

## 11. 評価されている点・不満点

**良い**: 派遣前の準備で全部決まる緊張感、眺めるだけの手軽さ、施設シナジーと育成の幅、ユニークのイベント、戦闘を簡素にして探索を速くした判断

**悪い**: 序盤が難しく半年でゲームオーバーになる人が多い、軌道に乗ると赤字にならず単調、イベント量が少ない、シナリオが希薄、3年目以降は大家の台詞が毎月同じ、バグが多い(鍵、離脱、メール1000通)

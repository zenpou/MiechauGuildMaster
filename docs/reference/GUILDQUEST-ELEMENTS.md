# 現行ゲームの要素一覧(新プロジェクトの土台)

> 2026-10-10 時点の `src/core`・`src/data`・`docs` から抽出。数値はすべて実装値。
> 新プロジェクトの設計時に「残す / 作り直す / 捨てる / 追加する」を判断するための棚卸し。評価や提案は含めない。

## 1. 作品の前提

| 項目 | 内容 |
|---|---|
| タイトル | ギルドクエスト 〜見えちゃうギルドマスター〜 |
| 主人公 | 現代日本の人事部5年目の会社員(名前変更可、既定「ユウト」)。終電を逃して異世界転移 |
| 固有能力 | 戦闘力なし。冒険者の能力・職業適性・性格・特性を本人だけが読める |
| 勘違い構造 | 主人公は数字どおりに配置しているだけ → 周囲が「才能を見抜く賢者」と深読み → 噂 → 評判上昇 |
| 舞台 | ハルトの街。灰竜が地下水路を塞ぎ、井戸が濁り始めている |
| 目標 | 30日目の市の査定までに灰竜を討伐 |
| 失敗条件 | なし。死亡なし、ゲームオーバーなし。期限超過後も続行できる拡張エンドへ |
| ジャンル | 物語付きギルド経営シミュレーション(自動探索・自動戦闘) |
| プラットフォーム | Web/PWA(TypeScript + Vite、素のDOM)、localStorage保存、GitHub Pages配信 |

## 2. 1日の流れ(コアループ)

```
募集を見る → 能力・適性を確認 → 雇用 → 転職・編成 → 依頼を選ぶ → 方針・回復薬を決める → 派遣
→ (出発時に全行程を決定論的にシミュレート、結果は帰還日まで非公開)
→ 「次の日へ」 → 給与・維持費 → 帰還・ログ閲覧 → 報酬・負傷・治療費・関係値・経験値 → 施設強化 → 次の編成
```

- 1日に派遣できる隊数に制限なし(人数が許す限り複数隊を同時運用できる)
- 待機中の冒険者は毎日 疲労-25、負傷日数-1
- 日送り時に 辞職判定 → 候補者入れ替え → 評判の節目 → 個人イベント(最大1件) → 勘違いイベント解決

## 3. 冒険者

### 3.1 パラメータ

| 区分 | 項目 | 値域・式 |
|---|---|---|
| 基礎能力(8) | HP / 腕力 / 守備 / 魔力 / 素早さ / 器用さ / 探索 / 採取 | HP 48〜78、他は 4〜14 程度の釣鐘分布 |
| 職業適性 | 剣士 / 狩人 / 術師 それぞれ 0〜100 | 本来職は 62〜98、それ以外は 10〜62。生成時40%は本来職と違う職に就いている(=転職で化ける) |
| 成長率 | 0.7〜1.35 | レベルアップ時の伸びと日給に影響 |
| レベル・経験値 | 次レベル必要 = 40×Lv | |
| 性格 | 6種のうち1つ | 撤退・戦闘・宝・罠・かばうの傾向、好き/嫌いな性格 |
| 特性 | 0〜2個(55%で1個、11%で2個) | 一部は未判明「？？？」。探索中に判明 |
| 疲労 | 0〜100 | 40超から能力低下(係数 = 1 − (疲労−40)/150)。70超で撤退しやすくなる |
| 負傷 | 療養日数 | 負傷中は派遣不可。治療費 = 日数×15G(治療所で −25%/Lv) |
| 忠誠 | 0〜100(初期55〜80) | 成功+3、負傷−3、赤字−4/日。15未満で辞職(固定メンバー除く) |
| 日給 | 10 + (適職戦力−50)×0.6 + (成長率−1)×14、最低8G | レベルアップで再計算。「怠け癖」で×0.85 |
| 年齢 | 16〜38 | 表示のみ |
| 記録 | 雇用日、派遣回数、撃破数 | 個人イベントの条件に使用 |

実効能力 = (基礎 + Lv成長) × 職業倍率 × 適性係数(0.65〜1.35、戦闘系のみ) × 疲労係数 × 特性補正

### 3.6 募集

- 候補者は毎日 1 + (評判Lv3以上で+1) + (40%で+1) 人到着、最大8人保持、期限で入れ替わる
- 候補者の質は評判レベルで上昇(quality = (Lv−1)×0.2、Lv2開始確率も上昇)
- 契約金 = 日給×4日分。宿舎定員 6 + 2×宿舎Lv
- 「才能」判定: 成長率1.2以上 または 適性90以上 → 勘違いイベントの種

## 6. 探索シミュレーション

- 1日3ステップ。依頼日数×3ステップで終了。各日の境で野営(疲労−8、戦闘後会話)
- 各ステップで、探索地・依頼種別・方針の重みからイベントを1つ抽選
- 各ステップ後、隊の平均HP比が撤退しきい値(方針 + 隊長の撤退傾向×0.6 + 疲労70超で+0.08)を下回れば撤退
- 出発時に結果を確定し、帰還日に開示。同seed・同条件なら同結果(mulberry32、`hash(seed, タグ, カウンタ)`)

| 商人 | merchant | 道中の売買 |

### 戦闘ルール

- 速度順ターン制。命中 = 速度差で判定、会心8%(×1.5)、与ダメ = 攻撃×倍率 − 守備×0.5(±10%)
- 職業スキル(CT制)、術師の回復魔法、回復薬の自動使用、「かばう」(性格のcover値)、臆病の硬直
- 敵AI: ランダム / 弱者狙い / 強者狙い。ボスの範囲スキル
- 撤退(fled)、全滅(wiped)。全滅しても死なず負傷で帰還

### 帰還時の処理

- 報酬 + 戦利品 + 素材売却、評判、治療費、忠誠、経験値(依頼exp × 成否 × 方針倍率 + 撃破exp/人数、×特性×訓練所)
- 負傷(療養日数)、疲労加算、関係値の反映、特性の判明、レベルアップ通知
- 「帰還のひとこと」: 参加者全員が成功/未達成/撤退/全滅別に話す。固定4人は専用、他は性格別、記録に固定保存
- 冒険ログ: 数値ではなく「誰が何をして何を言ったか」中心。種別 narration / combat / talk / event / relation / result

## 7. 関係値

- 2人ごとの値 −100〜100。初期値は性格の好き/嫌いから算出
- 探索中の出来事(かばう+3、会話、喧嘩、協力)で変動。ログに行として表示
- ラベルと記号で表示。編成時の相性警告に使用

## 8. 評判と勘違いイベント

- 評判は5段階(しきい値 0 / 8 / 20 / 35 / 55)。応募者の数・質、依頼解放に影響
- 勘違いイベント(19種): プレイヤーの行動がタグになり、日送り時に抽選 → 周囲の深読み台詞 → 噂 → 評判+2〜+5 → 主人公の「本音」

| タグ | きっかけ |
|---|---|
| hire_talent / hire_cheap_newbie | 才能ある候補 / 安い新人を雇った |
| job_change_big | 適性差25以上の転職 |
| dispatch_newbie_gather / dispatch_safe_weak / dispatch_split_pair / dispatch_potions | 新人を採取へ / 弱い隊を安全第一で / 仲の悪い2人を分けた / 薬を多く持たせた |
| return_first_success / return_retreat_safe / return_success_clean / return_underdog | 初成功 / 無傷で撤退 / 3人以上無傷で成功 / 推奨の8割未満で成功 |
| day_idle / rest_tired / reject_expensive / facility_built / rep_milestone | 何もしない日 / 疲労70超を休ませた / 高額候補を見送った / 施設建設 / 評判の節目 |

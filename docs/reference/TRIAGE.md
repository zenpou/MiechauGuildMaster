# 新プロジェクト 要素の仕分け(残す / 作り直す / 捨てる / 追加)

> 2026-10-10。元: [現行要素一覧](../GAME-ELEMENTS.md)、[参考作品の要素](../REFERENCE-OREHATA.md)、ここまでの設計対話。
> 新プロジェクトの主軸は「冒険者を集めてパーティーを組み、マップ上の各地へ派遣してダンジョンを踏破し、育てる」。
> アイテムは装備・薬・建材・納品の手段。物語の到達点はドラゴン討伐。全体の日数制限はなし。

凡例: **残す** = 現行をそのまま流用 / **作り直す** = 現行の骨は使うが形を変える / **捨てる** = 新作に持ち込まない / **追加** = 現行にない新要素 / **保留** = 第二部以降か、試作後に判断

## 1. 作品の前提

| 要素 | 判定 | 新作での形 |
|---|---|---|
| 主人公の「能力・適性・性格が見える」 | 残す | 募集・編成・転職の判断材料。数字に出ないもの(本音・不満・好き嫌い)はメールと行動でしか分からない、という対比に使う |
| 勘違い構造(合理的な配置 → 周囲が深読み → 評判) | 作り直す | 評判の上がり方として残すが、台詞は新キャスト・新舞台で書き直す |
| 現代の人事部出身の会社員という出自 | 保留 | 新主人公の設定を決めるときに再検討 |
| 30日の期限・灰竜討伐 | 作り直す | 全体期限は廃止。ドラゴン討伐は物語の到達点として残し、到達は育成と装備で決まる |
| 死亡なし・ゲームオーバーなし | 残す | 全滅は負傷+救助費用+持ち帰り素材の喪失 |
| 既存の7人・プロローグ・14章 | 捨てる | 世界・キャラ・物語は全部新規 |
| Web/PWA、TypeScript/Vite、localStorage保存 | 残す | 乱数・セーブ・自動プレイ計測の仕組みも流用 |
| 管理卓UI・ストーリープレイヤー | 作り直す | ストーリープレイヤーの再生エンジンは流用、画面構成はマップ3層に合わせて組み直す |

## 2. 時間と進行

| 要素 | 判定 | 新作での形 |
|---|---|---|
| ターン制(「次の日へ」) | 残す | |
| 出発時に結果を確定し帰還日に開示 | 残す | 複数隊の同時運用が容易。ワールド移動中も同じ |
| 段階解放のチュートリアル(1〜6日目) | 作り直す | 解放の順は新システムに合わせる(拠点 → 近場のダンジョン → 工房 → ワールド) |
| エンド2種(討伐・期限超過) | 作り直す | 討伐エンド1種+討伐後の継続。期限超過エンドは不要 |
| 依頼ごとの締め切り | 追加 | 受注期限と納期。過ぎると消えて評判微減。受けなければ損なし |
| 月末家賃のゲームオーバー(参考作) | 捨てる | 自由なプレイの方針と逆 |
| 実績リスト(参考作のチェックリスト) | 追加 | 期限なし進行の達成感と解放条件の受け皿。経験値ボーナス、ユニークの加入条件 |
| 周回・引き継ぎ(参考作) | 保留 | |

## 3. マップ

| 要素 | 判定 | 新作での形 |
|---|---|---|
| 探索地3つをリストから選ぶ | 捨てる | 3層マップに置き換え |
| 拠点マップ | 追加 | 移動なしの区画図。施設を置く。隣接シナジーだけが配置の意味 |
| ワールドマップ | 追加 | ノードと道。街・村・ダンジョン入口・中継地。地理は最初から全部見える。開いていくのは「ダンジョンの確認」「隠し場所」「近道」「道の危険度」「街の情報」 |
| 他の街 | 追加 | 依頼の発生源、固有の職人、募集の幅。護衛・運搬依頼で道を使う |
| ダンジョンマップ | 追加 | ダンジョンごとに固定の手作りマップ。複数フロア、階段、扉と鍵、隠し通路、採取ポイント、敵の巣、ボス部屋、シンボルモンスターの位置 |
| 探索率と累積マッピング | 追加 | 踏んだマスを累積保持。既知のマスは最短で進み、未知は手探り。100%で報酬+指定狩り+ボス直行+隠しエリア |
| 移動経費(参考作) | 作り直す | 金ではなくワールドの往復日数と中継地で表す。遠征ほど隊の拘束が長い |
| 天候(参考作) | 保留 | 面白いが調整項目が増える。試作後 |

## 4. 派遣

| 要素 | 判定 | 新作での形 |
|---|---|---|
| 編成最大4人、隊長指定 | 残す | 2〜4隊を同時に運用 |
| 方針6種(安全第一〜強敵優先) | 残す | 行動種別と組み合わせる |
| 回復薬の持ち込み | 作り直す | 消耗品一般に拡張(回復・解毒・松明・地図の切れ端) |
| 見込み表示(80回試算) | 作り直す | 残すが、未踏部分は「不明」と出す。地図が埋まるほど見込みが正確になる |
| 行動種別の指示 | 追加 | 探索 / 採集(対象素材) / 討伐(対象モンスター、100%で解放) / ボス / 踏査(新ダンジョンの1F) / 護衛・運搬(ワールド) |
| 1日1隊の派遣制限 | 捨てる | 現行にもないが、新作でも設けない |
| 派遣中の呼び戻し | 追加 | ワールド上で帰還方向に切り替える指示だけ可能 |

## 5. 探索・戦闘

| 要素 | 判定 | 新作での形 |
|---|---|---|
| 1日3ステップのイベント抽選 | 作り直す | ステップ=マップ上の移動に置き換える。イベントは踏んだマスの種類(採取点・罠・宝・敵の巣)で決まる |

| 全滅=負傷して帰還 | 作り直す | +救助費用(遠く深いほど高い)、持ち帰り素材の喪失 |
| 帰還ログ(誰が何をして何を言ったか) | 残す | 地図の更新差分も見せる |

## 6. 冒険者

| 要素 | 判定 | 新作での形 |
|---|---|---|
| 8能力・適性・成長率・特性(未判明あり)・疲労・負傷 | 残す | |
| 職業3種、転職無料 | 作り直す | 下級→上級の分岐を足す(例: 剣士→重戦士/魔法剣士)。転職条件にLvと施設 |
| 性格6種 | 作り直す | 戦闘・撤退の傾向に加えて、**探索の埋め方**を決める(確実に埋める/速いが雑/休憩が多い/分かれ道で悩む)。隊長の性格が地図の進み方を変える |
| 性格の好き嫌い → 関係値の初期値 | 残す | |
| 関係値(2人ごと) | 残す | 組み合わせイベントの条件に使う |
| 忠誠(辞職判定) | 作り直す | 見える式に: 1日+1、昇給承認+5、成功+3 / 負傷−3、全滅−20、昇給拒否−20。節目でメール、上限で専用スキル |
| 日給(戦力に比例) | 残す | |
| 募集(候補の入れ替わり、評判で質↑) | 作り直す | 条件指定の募集を足す。他の街で募集の幅が広がる |
| 契約金・宿舎定員 | 残す | |
| 固定メンバー(解雇不可) | 作り直す | ユニーク冒険者として再設計。加入条件(日数・実績・依頼)、固有スキル、固有依頼チェーン、離脱の可能性 |
| 汎用冒険者の個性 | 追加 | 趣味・特技・好きなもの・嫌いなもの(語彙リストから生成)。口調は性格別。行動履歴(どこに何回行ったか) |
| メール(受信箱) | 追加 | 挨拶、好感度の節目、昇給要望、退職警告、休みたい、仲間への不満、ダンジョンの噂、イベント進行、依頼の発生と完了。返信の選択(承認/保留/断る)が忠誠と関係値に効く |
| 昇給要望の無視で離脱 | 追加 | 退職警告 → 自己退職 → 二度と戻らない |
| 組み合わせイベント | 追加 | 特定2人を一定回数組ませると発生(友情・反発・結婚して2人で辞める等)。「取り返しのつかない要素」として明示 |
| 個人イベント8件 | 作り直す | ユニーク冒険者の依頼チェーンとして再構成 |
| スキル訓練 | 追加 | 訓練所で日数+費用。アクティブ/パッシブ |
| ポテンシャル高低(参考作) | 保留 | 成長率と特性で表現できているため、まず不要 |
| 冒険者の所持金制(参考作) | 捨てる | 経営の見通しが悪くなる |
| 非戦闘配置(施設勤務) | 追加 | 待機中の冒険者を工房・調合所に勤務させる。採取・器用さなど戦闘以外の能力の使い道 |

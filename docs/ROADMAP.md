## フェーズ1: 1ダンジョン・1隊・探索率(最小の縦切り) — 2026-10-10 完了(VERIFICATION.md 参照)

- ダンジョン1つ(1フロア、10×10程度)を JSON で手書き。採取ポイント・敵の巣・宝・罠
- 冒険者の生成(現行の `adventurer.ts` を移植)、固定の4人
- 派遣: 行動種別「探索」のみ。日数指定。出発時に全行程を確定
- 探索シミュレーション: マス移動。既知は最短、未知は手探り。踏んだマスを累積。探索率を保持
- 自動戦闘(`combat.ts` 移植、装備なし)
- 帰還ログと地図の表示(方眼紙風、既知/未知/今回踏んだ)
- `sim.ts`: 同じダンジョンに30日通わせて探索率の推移を出す
- **確認したいこと**: 地図が埋まると同じ日数で深く行ける感触があるか → **出た**(最深 12.0→20.8)。持ち越し: 経済が赤字(フェーズ4)、敵が弱い(フェーズ3)、定数のJSON化(フェーズ2)

## フェーズ2: 行動種別と隊長の性格 — 2026-10-10 完了(VERIFICATION.md 参照)

- 採集(対象素材)・討伐(対象)・ボス・踏査を追加
- 性格6種に探索挙動の係数(未踏へ踏み込む・埋め残しを潰す・速度・休憩しきい値・分かれ道の迷い・寄り道の対象。DESIGN 第6節の表、初期値は `personalities.json` に入れてある)
- 方針6種を移植
- 見込み表示(未踏は不明)
- 複数隊(最大4)の同時派遣
- **確認したいこと**: 隊長を変えると地図の埋まり方が目に見えて変わるか → **変わる**(勇敢: 最深22で88%、仲間思い: 最深18で99.5%、強欲: 67%)

## フェーズ3: 素材・工房・装備 — 2026-10-10 完了(VERIFICATION.md 参照)

- ダンジョン固有素材、採取ポイントからの入手、ドロップ
- 拠点マップ(5×5)に施設を置く。宿舎・工房・調合所・治療所・訓練所の5つから
- クラフト: 素材→装備(武器・防具・装飾)・回復薬。日数
- 装備の能力加算と属性耐性を戦闘に反映
- ダンジョン2つ目(手前の素材で作った装備がないと厳しい難度)
- 隣接シナジー 3組だけ
- **確認したいこと**: 「次へ行くには手前の素材」の鎖が機能するか → **装備の効き目としては機能**(坑道の失敗率 37%→5%)。自力で作る経済はフェーズ4の依頼収入が前提

## フェーズ4: ワールドと依頼 — 2026-10-10 完了(VERIFICATION.md 参照)

- ワールドマップ(拠点+街2+ダンジョン3+中継地1)。移動日数、危険度
- 依頼の生成(納品・討伐・探索・護衛)と締め切り。締め切りなしの解放依頼を1本(ミスリル納品→レシピ解放の型)
- 評判、勘違いイベントの仕組み移植(台詞は仮)
- 募集(候補の入れ替わり)、契約金、日給、赤字
- `playstyles.ts`: 隊の数・施設の有無・探索率を上げるかで遊び方を分けて60日を比べる
- **確認したいこと**: 締め切りだけで進行の圧力が十分か → **十分**(締め切り優先 +5743G・評判+11.7、依頼なしは−8152G。報酬は1.5倍に調整)

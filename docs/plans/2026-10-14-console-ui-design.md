# 本編UIのコンシューマーゲーム化 設計書(2026-10-14)

物語(紙芝居)の見た目は整ったが、本編の画面は system-ui フォント・素のボタン・罫線の表・10個のタブグリッドで「HTMLそのまま」に見える。本編を紙芝居プレイヤーと同じ系統(JRPGウィンドウ系: 紺の半透明パネル・金の縁・背景絵)に揃える。

## 決めたこと

| 項目 | 決定 | 理由 |
|---|---|---|
| 見た目の系統 | JRPGウィンドウ系(紺+金+背景絵) | 紙芝居プレイヤーが既にこの系統。章→本編の切り替えで違和感を出さない |
| 範囲 | 枠組み(HUD・コマンドバー・窓)を変え、各タブの中身は CSS で塗り替える | 各タブの DOM を残せばブラウザ検証14件がほぼそのまま通る |
| 端末 | 両方(レスポンシブ)。広い画面は左にコマンド列、狭い画面は下にコマンドバー | PWA・名簿のカード化への投資を活かす |
| フォント | 見出し・HUD の数字・コマンド名だけ Shippori Mincho のサブセット woff2。本文・表は端末のゴシック | オフライン PWA なので同梱が要る。使う文字だけ抜けば数十KB |
| アイコン | インライン SVG を本体が描く(線画・単色) | 素材パイプライン不要、色を CSS で変えられる |
| 狭い画面の下バー | 5個×2段で10個を全部出す | タップ一回でどこへでも行け、ナビ巡回の検証もそのまま |

## 1. 画面の骨組み

```
広い画面(≥900px)                       狭い画面
┌──────────────────────────────┐    ┌──────────────┐
│ HUD: 題 │ 日/G/評判/未読 │次の日へ│    │ HUD(2行に畳む) │
├────┬─────────────────────────┤    ├──────────────┤
│拠点│ ┌─ 窓の見出し ──────┐   │    │ ┌─ 窓 ─────┐ │
│派遣│ │                   │   │    │ │           │ │
│依頼│ │  タブの中身        │   │    │ │ タブの中身 │ │
│ …  │ │  (DOM はそのまま)  │   │    │ │           │ │
│記録│ └───────────────────┘   │    │ └───────────┘ │
└────┴─────────────────────────┘    ├──────────────┤
                                     │ ◆◆◆◆◆ 5個    │
                                     │ ◆◆◆◆◆ 5個    │
                                     └──────────────┘
```

- **色トークン**: `storyPlayer.css` の `--vn-*`(紺 `#0e1719` / `#142326` / `#1d3033`、金の縁 `#8e7650`、文字 `#f7f0df`、薄い文字 `#b7c0b7`、強調 `#efc878`)を `src/ui/tokens.css` の `:root` に昇格し、本編と紙芝居で共用する。紙芝居側は値の重複定義をやめてトークンを参照する
- **背景**: `body` の後ろにギルド事務所の絵 `public/art/backgrounds/guild-office-day-v1.webp` を `background-size: cover` で敷き、上に暗いビネット(中央 0.55 → 周辺 0.85 程度)を重ねる。パネルは半透明なので絵が透ける。文字と地のコントラスト比は 4.5 以上を目安に、ビネットの濃さで調整する
- **HUD**(上部に固定): 左にタイトル(`h1`、小さく明朝)。中央に「N日目」「1,250G(1日 −46G)」「評判 Lv2 ▰▰▱▱▱」「未読◆3」。右に「次の日へ」。今は拠点タブの中にある日数・G・評判・「次の日へ」をここへ移し、どのタブからでも日を送れるようにする。狭い画面では2行に畳む(1行目: 日数・G・次の日へ、2行目: 評判・未読)
- **コマンド**: `nav.tabs` の10個のボタンはそのまま(ラベルの文字を最初の子に置き、SVG アイコンはその後ろ。並び順は CSS で入れ替える)。広い画面では左に縦列(アイコン+ラベル)、狭い画面では下に固定バー(アイコンの上に小さいラベル、5個×2段)。選択中は金の▶カーソルと下線、未読バッジは今の `.badge.unread` を札にする
- **窓**: タブの中身 `.tab-body` を `.window` で包む。金の細い縁、四隅に小さな飾り(CSS の疑似要素で描く)、上辺に窓の見出し(「名簿」「派遣」など、タブ名)を重ねる

## 2. 部品の塗り替え

| 部品 | 変える点 |
|---|---|
| フォント | 見出し(`h1`〜`h3`)・HUD の数字・コマンド名・窓の見出しを `"Shippori Mincho Subset", "Hiragino Mincho ProN", "Yu Mincho", serif`。本文はこれまで通り system-ui。数字は `font-variant-numeric: tabular-nums` |
| ボタン | 暗い地(`--panel-strong`)に金の細縁、高さ 40px 以上、角 2px。`primary` は金の地に濃紺の文字。`danger` は赤銅色の縁。押下中は内側に影。`link` はそのまま下線 |
| 表(名簿・台帳) | 罫線を消し、行ごとに薄い帯、見出し行は小さな金文字。狭い画面のカード化は今のまま |
| リスト(お知らせ・依頼・メール・在庫) | 左に◆、項目の間に金のヘアライン |
| バッジ | 角を落とした小さな札。色の意味(撤退・全滅・未読・危険度・達成)は今のまま |
| ヒント | 受付のノエルの顔(`public/art/faces/noel/worried.webp`)を左に置いた吹き出しにし、文面は彼女の台詞として書く(口調は `docs/story/characters/noel.md`)。`.hint` クラスは残す(ブラウザ検証が見ている) |
| トースト | 画面上中央の帯(戦利品の通知風)。`.toast` / `.toast.err` は残す |
| エンディングのモーダル | 同じ窓枠に揃える。`.modal.ending` は残す |
| 方眼の地図・ワールド SVG | 色を新パレットに寄せるだけ |
| 下の PWA バー | 窓の外、画面の最下部に薄く |

## 3. 実装

### ファイル

- 新設 `src/ui/tokens.css`: 色・寸法のトークン。`style.css` と `storyPlayer.css` の先頭で `@import`
- 新設 `src/ui/icons.ts`: コマンド10個の SVG パス(`viewBox="0 0 24 24"`、`stroke="currentColor"`)。`icon(id): SVGElement`
- 新設 `scripts/subset-font.cjs`: `artifacts/fonts/ShipporiMincho-Regular.ttf`(OFL、手元に置く。git は無視)から、`scripts/font-glyphs.txt` に書いた文字だけを抜いて `public/fonts/shippori-mincho-subset.woff2` を作る(devDependency `subset-font`)。出力は git に入れる。元の TTF が無ければ CSS のフォールバック(端末の明朝)で動く
- 変更 `src/ui/main.ts`: `header` を HUD に、`tab.view()` を `.window` で包む、コマンドボタンにアイコン
- 変更 `src/ui/home.ts`: 日数・G・評判・「次の日へ」の塊を HUD へ移す(拠点タブから消す)。ヒントに顔
- 変更 `src/ui/style.css`: 全面的に塗り替え。セレクタ名は残す
- 変更 `index.html`: フォントの `<link rel="preload">`

### 残すもの(ブラウザ検証 `scripts/browser-check.cjs` が見ている)

- `h1` のタイトル文字列(HUD の中に置く)
- `nav.tabs > button` 10個。各ボタンの最初の子がラベルの文字(アイコンはその後ろ)
- `#app .tab-body`、`.hint`(文面に「派遣」)、`.toast`、`.modal.ending`、`.plots .plot`、`ul.synergies > li`、`.world-map`
- 拠点を開いたときに「N日目」の文字が見える(HUD にあればよい)
- どのタブでも横にはみ出さない(`scrollWidth <= 表示幅`)。固定の下バーはこの検査に引っかからない

### 受け入れ条件

- `npm test`・`npm run build`・`npm run test:browser`(14件)が緑
- PC 1280×800 とスマホ 390×844 の前後のスクリーンショットを `docs/VERIFICATION.md` に記録
- フォントのサブセットが 100KB 以下

### 進め方

設計判断は本体で済んだので、実装は独立した4単位に分けて Opus のサブエージェントへ並列に出す。

1. トークンと部品(`tokens.css`、`style.css` の塗り替え、`storyPlayer.css` のトークン参照化)
2. HUD・コマンド・窓(`main.ts`、`home.ts`、`icons.ts`)
3. フォントのサブセット(`scripts/subset-font.cjs`、`font-glyphs.txt`、`index.html`)
4. ヒントの吹き出し・トースト・モーダルの揃え(`home.ts` のヒント部、`style.css` の該当節)

1と4、2と4は `style.css` と `home.ts` を共有するので、4は1・2の後に直列で行う。受け取りは本体で `npm test`・`build`・`test:browser` を再実行し、`git diff` を読んでから取り込む。

## やらないこと(今回)

- 各タブのレイアウトの作り直し(名簿の顔付きカード、派遣の左右分割など)。ロードマップの「名簿の顔表示」は別の依頼
- 背景絵の時間帯切り替え(昼・夕・夜)。まず昼の1枚で様子を見る
- アイコンの画像生成。線画 SVG で足りなければ後で Codex に頼む

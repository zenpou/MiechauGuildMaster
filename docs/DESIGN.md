## 0. 確定した方針(変えるときは理由を書く)

| 項目 | 決定 |
|---|---|
| 主軸 | 冒険者を集めてパーティーを組み、マップ上の各地へ派遣してダンジョンを踏破し、育てる |
| アイテムの位置づけ | 手段。装備・薬のクラフト、拠点の建材、街への納品(資金と評判) |
| 時間 | ターン制(「次の日へ」)。派遣は出発時に全行程を確定し、帰還日に開示 |
| 期限 | 全体の日数制限なし。締め切りは依頼単位 |
| 物語の到達点 | 最奥のダンジョンに棲むドラゴンの討伐で第一部完。討伐後も続行可 |
| 主人公 | 冒険者の能力・適性・性格が見える。勘違いで評判が上がる構造は残す。出自は未決 |
| キャスト・物語・画像素材 | 全部新規。現行の7人・台本・立ち絵は使わない |
| 規模 | 同時2〜4隊、冒険者は最大で十数人 |
| マップ | 3層: 拠点(移動なし) / ワールド(街・ダンジョン・道) / ダンジョン(固定マップ、累積マッピング) |
| ダンジョン操作 | 自動探索+出発時の指示(行動種別・方針・日数・持ち物) |
| 戦闘 | 現行の自動戦闘を流用し、装備と属性耐性を足す |
| クラフト・建設 | 拠点の施設で自分たちが作る |
| 失敗 | 死亡なし・ゲームオーバーなし。全滅は負傷+救助費用+持ち帰り素材の喪失 |
| 技術 | TypeScript / Vite / 素のDOM / Vitest / PWA。GuildQuestの core 設計を踏襲 |

## 1. コアループ

```
拠点で確認(帰還報告・負傷・在庫・工房の完成品・受信箱)
→ 人を整える(募集・転職・装備の付け替え・休養・訓練・施設勤務)
→ 隊を組む(2〜4隊。行き先・行動種別・方針・日数・持ち物)
→ 工房と建設に素材を入れる(完成まで数日)
→ 依頼を受ける(締め切り付き)
→ 「次の日へ」(移動・探索・戦闘・帰還は自動)
```

3つの成長軸はすべて「次のダンジョンへ進むため」に収束する:

| 軸 | 進み方 | 手段 |
|---|---|---|
| 人 | レベル、転職(下級→上級)、スキル、特性の判明、関係値 | 探索の経験値、訓練所 |
| 装備 | 素材 → 工房 → 隊に配る | ダンジョンの採取・ドロップ |
| 場所 | 地図が埋まる、次のフロア・次のダンジョンが開く | 探索率、鍵、道の開通 |

進行の圧力は「依頼の締め切り」と「日々の給与」で作る。

## 2. ワールドマップ

- ノードと道。拠点の街を中心に、他の街・村・ダンジョン入口・中継地(宿・野営地)
- 道には移動日数と危険度。往復日数+滞在日数=隊の拘束日数。中継地を開くと短縮
- **地理は最初から全部見える**(街・街道・日数は公知)。開いていくのはギルドとしての情報:

| 開くもの | 開き方 |
|---|---|
| ダンジョン入口の確認 | 噂で位置は分かるが未確認。踏査隊か街の依頼で確定 |
| 隠された場所(遺跡・洞窟・塔) | ダンジョン内の地図や文献、酒場の噂、他の街の依頼 |
| 近道・裏道 | 踏査、住民との関係 |
| 道の危険度 | 最初は不明。隊が通ると実測値に更新。護衛依頼の見積もりに効く |
| 街の情報(依頼の傾向・職人・募集) | 訪れると開く |

- 護衛・運搬依頼はワールドの道を使う。道の危険度×隊の戦力で判定、途中で戦闘イベント
- 派遣中の隊はワールド上に現在位置を表示。呼び戻し(帰還方向への切替)だけ可能

## 3. ダンジョンマップ

- ダンジョンごとに固定の手作りマップ。グリッドの部屋と通路。複数フロア、階段、扉と鍵、隠し通路、採取ポイント、敵の巣、ボス部屋、シンボルモンスターの固定位置
- 画面では方眼紙に描いた地図として見せる
- **探索率**: 踏んだマスの割合を累積保持。隠し通路込みで100%にすると報酬(鍵・地図の売却・称号)+指定狩り+ボス部屋直行+隠しエリア
- **地図が効く**: 既知のマスは最短で進み、未知は手探り(1ステップの進行が落ちる)。地図が埋まるほど同じ日数で深く行ける
- 出発時の指示:

| 指示 | 隊の動き |
|---|---|
| 探索 | 未踏のマスを優先して埋める |
| 採集 | 既知の採取ポイントを巡る。対象素材を指定 |
| 討伐 | 敵の巣を巡る。対象モンスターを指定(100%で解放) |
| ボス | ボス部屋へ直行(到達済みなら) |
| 踏査 | 入口のみ既知の新ダンジョンに入り、1Fの地図を作る |

- 加えて方針(安全第一〜強敵優先)、日数、持ち物
- **隊長の性格が探索の埋め方を決める**(参考作から): 確実に埋める / 速いが探索済みを回る / HPが減ると休憩 / 分かれ道で悩む / 並行して埋めて無駄が多い
- 全滅: 死なない。負傷して戻る。遠く深いほど救助費用が高く、持ち帰った素材を失う
- 鍵は別ダンジョンの隠し通路にあり、遺跡の扉を開ける
- 保留: 天候、3すくみの生態系・希少種、乱獲ペナルティ

## 4. 拠点マップと施設

- 移動なしの区画図(5×5マス程度、拡張可)。配置の意味は隣接シナジーのみ
- 施設は15種前後に絞る:

| 系統 | 施設 | 役割 |
|---|---|---|
| 住居 | 宿舎 | 雇用上限 |
| 生産 | 工房(武器・防具)、調合所、製材所・石切場 | 素材→装備・消耗品・建材。完成まで数日。勤務者で速度↑。製材所・石切場は建材を少量産出 |
| 育成 | 訓練所、図書室 | 経験値↑、スキル習得、転職条件 |
| 回復 | 治療所、浴場 | 負傷日数・疲労回復 |
| 情報 | 地図室、酒場 | 隠し通路の発見率、ダンジョンの噂、募集の質 |
| 事務 | 受付、倉庫 | 同時受注数、保管上限 |

- 隣接シナジー: 隣り合う2施設の組で効果が足される。10〜15組に絞り、ゲーム内で一覧表示(隠さない)
- 建設: 建材+資金+日数。維持費は施設ごとに少額。壊すと建材の一部が戻る
- 非戦闘配置: 待機中の冒険者を施設に勤務させる。採取が高い者は調合所、器用さが高い者は工房

## 5. アイテムと装備

- 素材: ダンジョンごとに固有。装備の性能は素材で決まる → 次のダンジョンへ行くには手前の素材が要る
- 装備: 武器1・防具1・装飾1。防具は軽・中・重で職業ごとに可否。能力加算+属性耐性+特殊効果(罠回避、採取量↑)
- 消耗品: 回復薬、解毒薬、松明(探索率↑)、地図の切れ端(隠し通路)
- 積載: 隊には持ち帰り上限がある。採取・ドロップ・運搬の荷物はこれに収め、満杯なら帰るしかない。ギャザラー役の腕力で増える。採集隊と討伐隊で隊の形が変わる理由
- 納品: 街の依頼の中心。資金と評判の主な出口。売却はいつでも可だが依頼より安い
- 捨てる: アイテム生成機(ガチャ)、冒険者の所持金制

## 6. 冒険者・育成・メール(2026-10-10 確定)

- 残す: 8能力、適性(0〜100)、成長率、特性(未判明あり)、疲労、負傷、日給(戦力比例)、契約金、宿舎定員、関係値
- 役割: **アタッカー / タンク / ヒーラー / スカウト / ギャザラー(採取+運搬)** の5つ。依頼6種が隊に求めるものはこの5役で表す(討伐=攻・守・癒、探索・踏査=斥候、納品・運搬=採取、護衛=守・癒)
- 適性: 役割ごとに0〜100。周囲は一番高い役しか見ないが、主人公は二山の適性(例: 斥候60・採取65)から上級の向き先が分かる。勘違い構造の機械的な源
- 職業: 下級5(役割1つの専門)→ 上級5(隣り合う2役)。五角形 剣士→戦士→僧侶→採取士→斥候→剣士 の隣同士を組にするので、各下級から分岐2つ、各上級へ入口2つ。転職条件は入口となる下級のLv N+訓練所。適性にしきい値は設けず性能にだけ効く(前作踏襲)

| 下級(役割) | 上級 | 上級の役割 | 入口 |
|---|---|---|---|
| 剣士(アタッカー) | ウォーロード | アタッカー+タンク | 剣士 / 戦士 |
| 戦士(タンク) | パラディン | タンク+ヒーラー | 戦士 / 僧侶 |
| 僧侶(ヒーラー) | アルケミスト | ヒーラー+ギャザラー | 僧侶 / 採取士 |
| 採取士(ギャザラー) | トレジャーハンター | ギャザラー+スカウト | 採取士 / 斥候 |
| 斥候(スカウト) | アサシン | スカウト+アタッカー | 斥候 / 剣士 |

- スキルは役割ごとに1つ(強打・かばう・回復・罠解除/先読み・追加採取/積載増)。上級は2役分を持つ。職固有スキルは作らない。性能の天井は下級の専門、幅は上級。数値は sim で決める
- 落とした組(攻+癒、守+斥、癒+斥、攻+採、守+採): 向かい合う役なので上級なし。適性が離れた2役に高い人は下級のどちらかに留まる。これも「見えるから悩む」要素
- 性格: 現行6種を維持。戦闘・撤退の傾向に加え、**隊長の性格が地図の埋め方を決める**。探索挙動は6係数(未踏へ踏み込む / 埋め残しを潰す / 速度 / 休憩しきい値 / 分かれ道で悩む / 寄り道の対象)。実数値は sim で調整し、ここでは方向だけ決める

| 性格 | 未踏へ踏み込む | 埋め残しを潰す | 速度 | 休憩 | 分かれ道 | 寄り道 | 埋まり方 |
|---|---|---|---|---|---|---|---|
| 慎重 | 低 | 高 | 遅 | 早め(HP60%) | 迷わない | なし | 入口から同心円状。深くないが穴がない |
| 勇敢 | 高 | 低 | 速 | 遅い(30%) | 迷わない | 敵の巣 | 奥へ一直線で戦闘多め。途中は穴だらけ |
| 強欲 | 高 | 低 | 中 | 普通 | 少し | 宝箱・採取点 | 宝のある方へ伸びる。まだら |
| 仲間思い | 中 | 中 | 中 | 仲間の誰かがHP50% | 少し | 負傷者が出たら引き返す | 堅実だが距離が伸びない |
| 自信家 | 高 | 低 | 速 | 遅い | 即決(外れも多い) | なし | 最深到達は速いが手ぶら。当たり外れ |
| 臆病 | 最低 | 中 | 遅 | 早め | 立ち止まる | 敵を避けて迂回 | 既知の道をなぞって少しずつ広げる。負傷が少ない |

前へ出る3つは「何に寄り道するか」、守る3つは「何を基準に止まるか」で差をつける。
- 忠誠を見える式に: 目盛り0〜255、初期40〜60。1日+1、昇給承認+5、成功+3 / 負傷−3、全滅−20、昇給拒否−20。節目 50 / 120 / 255 でメール、255で専用スキル。上限到達が80〜100日目(ドラゴン到達の目安と重なる)になるよう、値は sim とテストプレイで調整してよい
- メール(受信箱): 10種。返信の選択が忠誠と関係値に効く。「見える能力」では分からないものがここで分かる。日給はLvアップで自動に上がらず、**本人の昇給要望を承認して初めて上がる**(人件費を握れる代わりに忠誠で払う)。数値は sim とテストプレイで調整可

| メール | 発火条件 | 返信 | 効果 |
|---|---|---|---|
| 挨拶 | 雇用の翌朝 | なし | 趣味・好き嫌いの一部が文面に出る |
| 忠誠の節目 | 50 / 120 / 255 に初到達 | なし | 本音が少し見える。255で専用スキル |
| 昇給要望 | Lvアップ後の再計算日給が現在より一定以上高い | 承認(+5、日給更新)/ 保留(0、7日後に再送)/ 断る(−20) | 保留は2回まで、3回目は断る扱い |
| 退職警告 | 昇給拒否2回連続、または忠誠30未満 | 昇給して引き留める(承認扱い)/ 放置 | 放置7日で自己退職 |
| 自己退職 | 警告から7日、または忠誠10未満 | なし | 候補に二度と現れない |
| 休みたい | 疲労70超のまま派遣に組まれた翌日 | 休ませる(+2)/ 断る(−5、次の派遣で能力低下) | |
| 仲間への不満 | 関係値−40以下の相手と連続3回同じ隊 | 分ける(+2)/ そのまま(−3、喧嘩率↑) | |
| ダンジョンの噂 | 酒場あり、または探索率50%・100%到達 | なし | 隠し場所・近道の候補をワールドに表示 |
| 依頼の発生 / 完了 | 街で依頼が生成 / 納品完了・期限切れ | なし | 受注画面へのリンク |
| イベント進行 | ユニークの依頼チェーン条件達成 | 受ける / 断る | 断ると離脱フラグの可能性 |
- 汎用冒険者の個性: 趣味・特技・好きなもの・嫌いなもの(語彙リストから生成)、性格別の口調、行動履歴
- ユニーク冒険者: **6人 = 5役に1人ずつ+ドラゴン筋の1人**。5役の5人は各役割の見本で、依頼チェーンの報酬をその役の上級職・レシピに結びつける。初期加入2人、残りは日数・実績・依頼で加入。6人目は物語の到達点(ドラゴン)に直結する別枠。各人: 加入条件、固有スキル、固有依頼チェーン(3〜4段。納品/N回派遣/単独ボス討伐 → レシピ・転職・スキル変化)、離脱の可能性、立ち絵3ポーズ、専用台詞。組み合わせイベント(特定2人を一定回数組ませると発生)はユニーク同士の組で作る
- スキル訓練: 訓練所で日数+費用
- 転職Lv: 初期値 Lv10(前作は30日で平均Lv7、新作は90日想定なので中盤に来る値)。sim で調整
- 未決: なし(数値は sim とテストプレイで調整)

## 7. 依頼とワールド(2026-10-10 確定)

- 街: **拠点+街2+村1**。街ごとに性格を持たせる(例: 鍛冶の街=武器防具のレシピ / 学院の街=薬・魔法のレシピと図書 / 山村=素材と採取士の募集)。各街の先に1〜2ダンジョン、村の奥がドラゴン方面。護衛・運搬のルートが3方向。名前は第8節
- 街ごとに依頼が発生。種別: 納品・討伐・探索・護衛・運搬・踏査。各依頼に受注期限と納期。過ぎると消えて評判微減。受けなければ損なし
- 依頼の生成: **テンプレート生成+手書き別枠**
  - 街ごとに毎日一定確率で1件生成。掲示板の上限は 拠点4・街3・村2。期限切れで消える
  - 種別の重みは街の性格で決まる(鍛冶の街=鉱石納品と討伐、学院=薬草納品と探索・踏査、山村=採集と運搬、拠点=全般と護衛)
  - 難度は評判Lvで段階解放。ボス・踏査・遠方護衛は上位
  - 内容は seed+日付から決定論的に生成(テンプレート+パラメータ)
  - 他の街の依頼はその街を一度訪れてから見える。以後はメール「依頼の発生」で届く
  - 手書きの別枠 = **解放依頼(締め切りなし)**: 達成すると何かが開く依頼。掲示板に消えずに残り、達成で開くものをゲーム内に明示する。例: ミスリル納品 → ミスリル装備のレシピ群解放(職人の開発依頼)、探索率100% → 鍵・称号(ダンジョン依頼)、ユニークの依頼チェーン → 上級職・固有スキル
- 締め切り: 基準は最短所要日数(拠点からの往復+現地日数)。倍率は sim で調整

| 種別 | 受注期限(掲示板に残る) | 納期(受注後) | 備考 |
|---|---|---|---|
| 納品 | 5〜7日 | 最短所要の約2倍(7〜14日) | 在庫があれば即納できる |
| 討伐 | 5〜7日 | 約1.5倍(6〜10日) | |
| 探索(○%まで) | 7〜10日 | 10〜15日 | 複数回の派遣を想定 |
| 踏査 | 10日 | 10〜15日 | 未知の場所なので余裕を持たせる |
| 護衛 | 出発日固定(3〜5日後) | 到着=出発日+道の日数 | 出発日に隊がいなければ失敗で評判微減 |
| 運搬 | 5日 | 出発から道の日数+2日 | 積載が必要 |
| 解放依頼 | なし | なし | 達成で開くものを表示 |
- 評判5段階(現行流用)。応募者の質・依頼解放・街の情報開示に効く
- 勘違いイベント: 発火タグの仕組みは流用、台詞は新規
